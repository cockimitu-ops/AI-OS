## What This Is
Fixed packages ("20 AI shorts/month including script, video, editing, analytics report") sold to businesses, not audiences. Nearly the entire technical side is already covered by existing skills and infrastructure — this project's actual job is closing the one real gap.

## The Real Gap: Sales, Not Production
Per the research: almost every capability needed to *deliver* this already exists — [[Hook_Writing]], [[Retention_Beat_Scripting]], [[CapCut_Production_Formatting]], the whole shared production pipeline in [[10_Projects/SocialMediaContent/README|SocialMediaContent]]. What doesn't exist yet is B2B acquisition: cold outreach, offers, pricing, closing. That can't be shortcut with AI and has to be actively built — this project is really about that skill, with delivery capacity already sitting there waiting.

## What This Project Draws On, Doesn't Duplicate
- Production capability: the full shared pipeline in [[10_Projects/SocialMediaContent/README|SocialMediaContent]] and `03_Capabilities/`
- Craft knowledge: `02_Systems/Content/Knowledge/` (general + horror, and whatever else a client's content needs)
- This project should never redefine how a hook, a script, or a caption gets made — it defines the *offer* and the *acquisition process* around production that already works.

## Status
Not launched. No offer defined yet, no outreach started. First real milestone: define 1–2 concrete package tiers and a price.
