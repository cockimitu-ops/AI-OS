## Focus and Style
Offensive security / ethical hacking specifically. Learning style: structured courses and videos, not open-ended hands-on labs — though TryHackMe's guided format sits close enough to "structured course" to work well here.

## Resources
- **TryHackMe — Pre Security path** (free) — the standard on-ramp: networking, Linux, and web fundamentals, guided rather than open-ended. Uses a browser-based Kali ("AttackBox") — no local install needed for this stage.
- **NetworkChuck** (YouTube) — networking and ethical-hacking-intro videos, explains the *why*, not just tool button-mashing.
- **Professor Messer** (free) — Security+ theory series, treated as a gold standard for foundational concepts even outside the cert itself.

## Kali Linux
Not needed yet for Pre Security (TryHackMe's browser-based AttackBox covers it). Once past fundamentals: VirtualBox + the official Kali VM image from kali.org/get-kali (not the ISO installer) — isolated, snapshot-able, standard beginner setup. Learn tool-by-tool in context (what TryHackMe's guided rooms already do), not by browsing all 600+ tools — TCM Security's own guidance, and the same principle as this whole project's learning style.

## The Non-Negotiable Rule
"Ethical" means only ever testing systems with explicit written permission. Not a formality — the actual legal line. TryHackMe's labs exist specifically so real technique can be practiced legally.

## Milestones (Pre-September Head Start)
- [ ] Weeks 1–2: Networking fundamentals (TCP/IP, ports, protocols) — TryHackMe Pre Security + NetworkChuck networking videos
- [ ] Weeks 3–4: Linux comfort + web fundamentals — continue TryHackMe Pre Security
- [ ] Before September: basic security concepts (CIA triad, common vulnerability types) — Professor Messer foundational videos
- [ ] September onward: formal coursework begins — this project continues as reinforcement/practice alongside it, not a replacement

## Why This Order
Networking and Linux before tools — skipping straight to hacking tools without understanding what they're doing underneath is the most common reason people bounce off ethical hacking early.
