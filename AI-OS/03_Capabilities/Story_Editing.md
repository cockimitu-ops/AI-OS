## What It Does
Applies [[Editing_Principles]]'s subtractive, single-concern-pass discipline to a complete draft — after [[Hook_Writing]], [[Retention_Beat_Scripting]], [[Cliffhanger_Creation]], and [[Ending_Design]] have all run, before [[TTS_Optimization]] and production formatting begin.

## Inputs
A complete draft — all parts, with every capability above already applied.

## Outputs
An edited draft, same structure, tightened per [[Editing_Principles]].

## Success Criteria
Every sentence in the edited draft still maps to exactly one purpose, per [[Reddit_Story_Workflow]]'s sentence-purpose rule. Any sentence that fails the purpose test in this pass is cut, not kept "because it's well-written" — see [[Editing_Principles]]'s purpose test.

## Validation
Was each editing concern — clarity, then pacing, then style — passed over separately, per [[Editing_Principles]], rather than all at once? A single-pass edit that tried to fix everything simultaneously is a process failure even if the output happens to be fine.

## Analytics Reference
Edited-vs-unedited draft length against eventual retention performance is an [[Experiment_Tracking]] candidate once enough drafts exist to compare.
