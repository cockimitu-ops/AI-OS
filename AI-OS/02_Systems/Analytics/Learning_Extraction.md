# Learning Extraction

Purpose: How a result becomes a specific, statable learning.
Last Updated: 2026-08-07
Status: Active
Related Documents: [[02_Systems/Analytics/README|Analytics]], [[Learning_Loop]], [[Knowledge_Promotion_Rules]]
Required Notes: [[Failure_Analysis]], [[Experiment_Tracking]]

---

A learning is a specific claim — "hooks under 3 seconds outperformed longer ones in this test" — not a vague impression. If it can't be stated specifically, it isn't ready yet. Analytics-side counterpart to [[Learning_Loop]]: that note defines *when* extraction happens; this defines what a learning looks like once extracted. Zero learnings from a completed project is a valid, common outcome.

In: an analyzed project/experiment. Out: zero or more statable learnings, each tagged promotion-candidate or not.
