# Metrics Framework

Purpose: How a metric is defined so it's reusable across any completed project.
Last Updated: 2026-08-07
Status: Active
Related Documents: [[02_Systems/Analytics/README|Analytics]], [[Success_Criteria]]
Required Notes: [[Success_Criteria]]

---

A metric measures an outcome against a stated expectation, not a number in isolation — "300 views" isn't a metric, "300 against an expected 1,000" is. Defined before a project completes, not invented afterward to fit what happened. A platform-specific number (views, watch time) is a raw signal, not a metric — this framework governs how signals become judgments; it doesn't define which signals to track, since that's platform-specific.

In: raw signal(s), stated Success Criteria. Out: a signal-against-expectation comparison, ready for [[Failure_Analysis]].
