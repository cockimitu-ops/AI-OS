## Core Principles
- The full cycle: completed work → [[Review_Process]] → [[Learning_Extraction]] → [[Knowledge_Promotion_Rules]] → recommendation → [[Knowledge_Promotion]] → permanent knowledge, capability, or system update. This note names the loop; it doesn't redefine any stage in it.
- The cycle only closes if a recommendation is actually acted on somewhere. A recommendation nobody reviews is a dead end, not an improvement. This note doesn't solve that — Analytics has no authority to force action — it just keeps the gap visible if one opens.
- Improvement is measured by whether the same failure recurs, not by volume of learnings produced. A system generating many unpromoted learnings that don't change future outcomes isn't improving, regardless of how much analysis happened.

## Inputs
The outputs of [[Review_Cadences]] over time.

## Outputs
A visible loop from "what happened" to "what changed" — and a visible gap where it didn't.

## Dependencies
[[Review_Cadences]] (the cadence that feeds it), [[Knowledge_Promotion_Rules]] (the last internal step before the loop leaves Analytics).
