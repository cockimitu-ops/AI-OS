# Knowledge Promotion Rules

Purpose: When an extracted learning is recommended for promotion — never performs the promotion itself.
Last Updated: 2026-08-07
Status: Active
Related Documents: [[02_Systems/Analytics/README|Analytics]], [[Learning_Loop]]
Required Notes: [[Learning_Extraction]], [[Knowledge_Promotion]]

---

Analytics recommends; it does not promote — the pipeline (Observation → Experiment → Validated Learning → Permanent Knowledge) is owned by [[Knowledge_Promotion]]. Recommended only if specific, reproducible in principle (not a one-off fluke), and doesn't contradict existing knowledge without explanation. A recommendation still goes through Knowledge Promotion's stages — this is a filter before that pipeline, not a bypass.

In: a statable learning. Out: promote-candidate or not, handed to [[Knowledge_Promotion]].
