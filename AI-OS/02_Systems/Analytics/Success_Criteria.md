# Success Criteria

Purpose: How "did this work" gets defined for completed work, before it's measured.
Last Updated: 2026-08-07
Status: Active
Related Documents: [[02_Systems/Analytics/README|Analytics]], [[Metrics_Framework]], [[Task_Specification]]

---

Set at task definition, not after the fact — governs [[Task_Specification]]'s existing Success Criteria field. A criterion without a threshold isn't one: "should perform well" isn't testable, "should exceed X" is. Multiple criteria can apply and don't need to agree — a project can succeed on retention and fail on reach at once; [[Metrics_Framework]] doesn't collapse that into one verdict.

In: a task's Objective. Out: one or more named, thresholded criteria.
