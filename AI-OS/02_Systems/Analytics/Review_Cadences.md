# Review Cadences

Purpose: The three interval options for running Review Process — merged from three near-identical notes (Sprint 022) since Daily/Weekly/Monthly differ only in interval, not in rule.
Last Updated: 2026-08-07
Status: Active

## Shared Rules (all three cadences)
- Scope is everything completed since the last review — not a rolling arbitrary window.
- A skipped review is logged as skipped, not silently absorbed into the next one.
- The cadence sets the interval; it doesn't redefine what a review does — that's [[Review_Process]].

## Monthly (the default)
A default, not a hard rule — the interval exists so review happens at all, not to fix the timing permanently.

## Weekly
The natural upgrade once Monthly's interval would let a real pattern — declining retention across several stories, for instance — run for weeks before being caught.

## Daily
A volume-triggered upgrade from Monthly, not a permanent replacement. Value is catching a systemic issue (e.g., a capability update that broke something) before it compounds across days of output — not catching every individual story's nuance. A single day rarely has enough volume for pattern-level Learning Extraction on its own.
