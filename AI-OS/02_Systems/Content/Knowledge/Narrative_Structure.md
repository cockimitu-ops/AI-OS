## Core Principles
- A complete structure needs a starting state, a disruption, escalating complication, a turning point, and a resulting state.
- Order can be resequenced for effect (starting mid-action, for instance), but every stage still has to exist somewhere in the telling.
- Compression is a structural choice, not a loss — cutting to only the stages that carry weight is what makes short-form narrative work at all.

## Key Concepts
- Setup / disruption / escalation / turning point / resolution
- In medias res (starting mid-action)
- Compression vs. completeness
