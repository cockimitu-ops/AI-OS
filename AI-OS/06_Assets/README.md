## Responsibility
Images, exports, and other binary or non-Markdown files that a Markdown file elsewhere in the vault needs to reference — including actual template *files* (e.g. a `.docx` or `.pptx` template), as distinct from the Template *Framework* governing how templates are structured, which lives in `01_Architecture/Templates/`. Nothing in this folder is a source of truth on its own — it supports files that are.

## Status
Empty. Populated as systems, capabilities, or workflows need supporting assets.
